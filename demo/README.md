# Demo

Ogni incremento della roadmap si chiude con una demo eseguibile in pochi minuti.

| # | Demo | Comando | Copione |
|---|---|---|---|
| 00 | Fondamenta: database, coda, worker, API e contratto OpenAPI | `bash demo/00-fondamenta/run.sh` | [COPIONE](00-fondamenta/COPIONE.md) |
| 01 | Accesso e shell: login OIDC, sessioni, CSRF, ruoli, progetti e membri, shell di Studio con ⌘K, tema e lingua | `KEEP=1 bash demo/01-accesso-e-shell/run.sh` | [COPIONE](01-accesso-e-shell/COPIONE.md) |
| 02 | Documenti: caricamento, estrazione del testo isolata, classificazione a regole, correzione del PM, RLS, eliminazione e conservazione | `KEEP=1 bash demo/02-documenti/run.sh` | [COPIONE](02-documenti/COPIONE.md) |
| 03 | Conoscenza: fatti con citazioni verificate, pseudonimizzazione, contraddizioni, vettori, RLS | `KEEP=1 bash demo/03-conoscenza/run.sh` | [COPIONE](03-conoscenza/COPIONE.md) |
| 04 | Fonti e alimentatori: ingest con token, feeder (file, cartella), Jira finto letto dal worker, credenziali cifrate, freschezza dei dati | `KEEP=1 bash demo/04-fonti/run.sh` | [COPIONE](04-fonti/COPIONE.md) |
| 05 | Chiedi: ricerca ibrida, risposta verificata frase per frase, contraddizioni, freschezza, avanzamento in tempo reale, storico | `KEEP=1 bash demo/05-chiedi/run.sh` | [COPIONE](05-chiedi/COPIONE.md) |
